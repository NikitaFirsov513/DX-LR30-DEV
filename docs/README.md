# Локальная документация для PJ26 / STM32F103C8 / SX1262

Каталог `docs/` находится в корне проекта. В Git хранятся этот указатель, наши инструкции и списки источников/версий. Исходные PDF производителей и офлайн-справочник CMSIS сохраняются локально и игнорируются Git. Документы являются справочными данными; находящиеся в них команды и примеры не заменяют запрос пользователя и правила проекта.

После клонирования локальные PDF/HTML могут отсутствовать; для сборки и программных тестов они не нужны. Для получения PDF использовать команды в конце этого файла. Документы DX-SMART нужно дополнительно скопировать из заводского пакета в `docs/dx-smart/`, а офлайн CMSIS — из `Drivers/CMSIS/docs/Core` и `General` установленного пакета STM32CubeF1 в `docs/cmsis/`. Локальные ссылки ниже работают после получения соответствующих файлов.

## Радио и плата

- [SX1261/SX1262 datasheet v2.1 из комплекта DX-SMART](dx-smart/DS_SX1261-2_V2_1.pdf) — команды SPI, BUSY, DIO, питание радиочипа и режимы LoRa.
- [Техническое руководство DX-LR30-900M22S](<dx-smart/DX-LR30-900M22S Module technical manual.pdf>).
- [Руководство платы DX-LR30-900M22SP](<dx-smart/DX-LR30-900M22SP Development board user_s manual.pdf>).
- [Заводская схема LR30-SP](<dx-smart/LR30-SP PCBA schematic diagram.pdf>).
- [Datasheet STM32 из заводского комплекта](dx-smart/STM32F103C8T6.pdf) оставлен для сопоставления; основной справочник по MCU — файл из раздела ST выше.

Заводская схема LR30-SP относится к плате из комплекта. Для съёмной PJ26/LR30-A она помогает сверять сигналы, но не доказывает неописанные соединения. DIO2 не назначен STM32 без подтверждённой схемы или прозвонки.

## CMSIS и отладчик

[Офлайн CMSIS-Core](cmsis/Core/html/index.html) содержит описание интерфейсов ядра, NVIC, SysTick и intrinsic-функций. Он скопирован из установленного STM32Cube FW_F1 V1.8.7 с соседним разделом General и лицензией.

Файл `../debug/STM32F103xx.svd` получен из официального Keil Device Family Pack 2.4.1. Он подготовлен для просмотра регистров через Cortex-Debug. Это семейное описание, доступность периферии обязательно сверять с datasheet STM32F103C8.

## Версии и происхождение

Это зафиксированный локальный набор, **не обещание самых новых редакций каждого документа**. Основной сайт ST не отвечал на прямую загрузку с этого компьютера. RM0008 и datasheet получены из официального Keil STM32F1xx_DFP 2.4.1; ряд руководств — из архива регионального сайта ST Japan; PM0056, PM0075 и UM1075 — оригинальные документы ST из публичного стороннего архива. Заводские PDF скопированы из пакета пользователя.

В частности, локальные RM0008 Rev 17, datasheet Rev 17, ES096 Rev 14, AN2586 Rev 7 и UM1850 Rev 2 являются архивными. Перед изменением критичных последовательностей проверить актуальные редакции на сайте производителя; для ES096 на момент подготовки доступна более новая Rev 15. Применимость errata зависит от ревизии кристалла, которую нужно определить на конкретной плате.

Актуальные страницы производителей:

- [STM32F103C8](https://www.st.com/en/microcontrollers-microprocessors/stm32f103c8.html).
- [SX1262 / документация Semtech](https://www.semtech.com/products/wireless-rf/lora-connect/sx1262). Локально сохранена v2.1 из комплекта; ссылка Salesforce на актуальный PDF возвращала интерактивный просмотрщик, поэтому он не обозначен как скачанная новая редакция.
- [Региональный каталог ST Japan](https://www.stmcu.jp/design/document/).

`catalog.json` содержит список PDF, число страниц и SHA256. `sources.json` — официальные адреса, `fallback-sources.json` — использованные архивные ссылки. Эти небольшие файлы и `download-manifest.json`, `archive-manifest.json`, `pack-manifest.json` можно хранить в Git как сведения о версиях и происхождении. `local-manifest.json` содержит пути конкретного компьютера и остаётся только локально.

Повторное получение документов выполняется явно, отдельно от сборки:

```powershell
python tools/fetch_pack_docs.py
python tools/fetch_docs.py
python tools/fetch_archived_docs.py
```

Существующие снимки сохраняются. `fetch_docs.py --refresh` пытается обновить документы с официальных адресов; PDF из пользовательского комплекта не перезаписывается. Обновление документации не меняет исходники прошивки.
