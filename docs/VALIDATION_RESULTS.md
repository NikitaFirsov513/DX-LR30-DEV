# Результаты проверки переноса на CMSIS

Дата: 5 ноября 2026. Проверки выполнены из корня проекта в ветке `codex/cmsis-workflow`. Базовый commit старого варианта: `f3bb779`. Изменения новой структуры оставлены в рабочем дереве.

## Выполнено

- `python tools/test.py` из корня проекта — PASS: обе ARM-сборки, память/векторы/HEX, распиновка, контрольные суммы vendor, C-тесты framing и radio, тесты ISP и выбора COM.
- Сборка Radio и UART установленным `unify_builder` EIDE с новой конфигурацией — PASS. Проверочный CLI использовал существующий .NET с разрешённым для этого процесса переходом на старшую версию runtime; системные настройки .NET не менялись.
- `python tools/verify.py --build-dir build/eide` — PASS для обоих target.
- BIN от CMake и EIDE совпадают побайтно для обоих target после фиксации порядка линковки.
- Workspace закрыт и повторно открыт в VS Code после регенерации EIDE. В интерфейсе подтверждены новые пути Build/Flash `build/eide/Radio`; старый HAL-кэш больше не используется. Настройки CMake IntelliSense исправлены только для этого workspace, конфигурация clang-format приведена к поддерживаемым параметрам.
- `flash.ps1 -Firmware build/eide/Radio/dx_lr30_pj26.hex -Port COM5 -DryRun` — PASS без подключённой платы. COM не открывался.
- Все 20 локальных PDF открыты PDF-парсером; записаны число страниц и SHA256. Часть документов архивных редакций, см. docs/README.md.
