# Устройство проекта

Это ручной проект на C11/CMSIS для PJ26 с STM32F103C8T6 и модулем DX-LR30-900M22S. Система работает без RTOS. CubeMX хранит справочное изображение конфигурации, а фактическую настройку выполняет код.

## Границы модулей

| Каталог | Ответственность |
|---|---|
| `app/` | Главный цикл, UART-пакеты, передача данных между UART и радио |
| `board/` | Подключения PJ26, безопасные начальные уровни, переключение RXEN/TXEN |
| `mcu/` | Регистры STM32, тактирование, GPIO, SPI1, USART1, TIM2/TIM3, EXTI, SysTick |
| `devices/sx126x/` | Инициализация радиочипа, состояния RX/TX/FAULT, переносимый интерфейс приложения, транспорт Semtech |
| `vendor/` | Неизменённый код ST/Arm и Semtech с контрольными суммами |
| `tests/` | Тесты настоящего кода обработки пакетов и радио с моделью ввода-вывода |
| `tools/` | Сборка, проверки, ISP-прошивка, поиск COM и получение документации |

`app/main.c` запускает модули и обрабатывает готовые события. Он не настраивает регистры и не знает номера выводов радио.
`board/pins.def` — таблица сигналов, портов, номеров выводов, режимов и начальных уровней. Она непосредственно включается в C-код; промежуточного генератора пинов нет. `board/config.h` хранит параметры платы, `devices/sx126x/radio_config.h` — параметры радио.

## Владельцы ресурсов

| Ресурс | Владелец | Настройка |
|---|---|---|
| RCC/Flash latency/SysTick | `mcu/clock.c` | HSE 8 МГц, PLL x9, AHB 72, APB1 36, APB2 72 МГц; тик 1 мс |
| GPIO/AFIO | `board/board.c`, примитивы `mcu/gpio.c` | Default remap; JTAG выключен, SWD сохранён |
| SPI1 | `mcu/spi.c` | Mode 0, 8 bit, MSB, software NSS, 4,5 МГц |
| USART1 | `mcu/uart.c` | 9600, 8N1, RX IRQ; передача из основного цикла |
| TIM2 | `mcu/timer.c` | Свободный счётчик 1 МГц для коротких задержек |
| TIM3 | `mcu/timer.c` | Однократное событие после 5000 мкс тишины UART |
| EXTI15 | `mcu/exti.c` | PC15/DIO1, нарастающий фронт, флаг события |

USART имеет приоритет 0, EXTI — 1, TIM3 — 2, SysTick — 15; используются четыре бита приоритета вытеснения. Обработчик UART добавляет байт и перезапускает таймер тишины. По таймеру либо при накоплении 255 байт формируется пакет. При переполнении очереди отбрасывается новый пакет целиком, число потерь сохраняется в `frames.dropped`. Ошибки USART считаются в `uart_error_count()`.

Доступ из main к очереди защищён коротким сохранением/восстановлением PRIMASK. Прерывание DIO1 не обменивается данными по SPI: оно устанавливает флаг, который обрабатывает `radio_poll()`.

## Состояния радио

`STARTING -> RECEIVING -> TRANSMITTING -> RECEIVING`. Ошибка транспорта переводит радио в `FAULT` и отключает RXEN/TXEN. При TX_DONE или TIMEOUT приём возобновляется. Если событие завершения передачи потеряно, через 6500 мс программа пытается вернуть радио в приём; это не считается подтверждением доставки.

Нет адресов, ACK, повторов и LoRaWAN. Одинаковая прошивка Radio устанавливается на обе платы. Приём отдаёт фактическое количество байтов, включая NUL, без трактовки пакета как строки.

Слово `hal` в именах `sx126x_hal_*` принадлежит интерфейсу транспорта Semtech. В этом проекте за ним стоит собственная реализация SPI/GPIO; библиотека STM32 HAL не подключается.

## Что изменилось относительно рабочего HAL-примера

Сохранены распиновка и параметры радиоканала. GPIO, RCC, SPI, UART, таймеры и EXTI переведены на CMSIS. Имена заводских глобальных переменных и HAL callback заменены на явные интерфейсы модулей.

Дополнительно исправлены перезапуск счётчика таймера тишины UART, учёт ошибок UART/переполнения очереди, возврат предела RX-пакета к 255 после короткой передачи, обработка ошибок SPI/BUSY и восстановление после потерянного TX IRQ. RXEN/TXEN переключаются сначала выключением прежнего направления; при старте TXEN=0, RXEN=1. Поэтому новый бинарный файл не идентичен старому и требует проверки на платах.

CubeMX отражает назначения пинов, базовые частоты и настройки UART/SPI. Он не является полным описанием логики таймеров, приоритетов, обработки ошибок или состояний радио.
